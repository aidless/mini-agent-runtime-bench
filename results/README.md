# results：空表语义与落数规范

> 本文档是 `results/` 的契约页。当前状态：零证据——`flip_rate_empty.csv` 仅一行表头、零数据行。
> 核心语义：**仅表头 = 诚实的零证据声明**，表示“尚未进行任何可记录的重放”；它绝不表示翻转率为零、绝不表示重放已做完、绝不表示结论稳健。

## 空 csv 语义

- `flip_rate_empty.csv` 有且仅有一行（表头）。门禁 A3 对此做精确断言：行数必须为一，表头必须与列契约逐字一致。
- 文件名中的 `empty` 是语义的一部分：只要文件仍以 `_empty.csv` 命名，就禁止包含任何数据行。
- 任何“看起来像结果”的行（即使 `flip_occurred` 填空或填否）在首个真实 `trace_id` 产生前一律视为编造，门禁判 FAIL。

## 列定义

表头（门禁逐字校验，顺序与拼写均不可变）：

`trace_id, task_id, condition, run_id, flip_occurred, flip_type, evidence_path, notes`

| 列 | 语义 | 落数前占位 | 落数时要求 |
| --- | --- | --- | --- |
| `trace_id` | 本次重放的追踪标识 | 无行（空表） | 非空，且可链回原轨迹的 `run_id` |
| `task_id` | 重放所依据的任务编号 | 无行（空表） | 必须与对应快照的 `task_id` 一致 |
| `condition` | 本次重放所处的扰动矩阵格点描述 | 无行（空表） | 必须是已冻结格点清单中的一项（清单 `TBD`，冻结前不得落数） |
| `run_id` | 被重放的原轨迹运行标识 | 无行（空表） | 必须是 W2 有效轨迹的 `run_id` |
| `flip_occurred` | 是否翻转（文字结论是否变化） | 无行（空表） | 只允许约定的文字取值（取值表 `TBD`，未定前不得落数） |
| `flip_type` | 翻转类型描述 | 无行（空表） | 必须引用已定义的翻转类型（类型表 `TBD`） |
| `evidence_path` | 重放证据的位置描述 | 无行（空表） | 必须可解析、可复核，禁止悬空 |
| `notes` | 备注 | 无行（空表） | 异常重放必须说明原因 |

## 将来落数规范（`trace_id` 链）

1. 落数前提（三者缺一即禁止落数）：扰动矩阵格点清单已冻结、裁判独立性标准已确定（W3 中当前均为 `TBD`）、门禁全 PASS。
2. `trace_id` 链：每一数据行的 `trace_id` 必须能沿“重放 → 原轨迹 `run_id` → 快照 `snapshot_id`”完整回链；断链的行无效，必须删除（删除后恢复空表语义）。
3. 落数即转段：首个真实数据行落盘之日，本仓库离开 pre-W1 空仓状态；落数者须在同一变更中把本文件的“当前状态”小节更新为首个 `trace_id` 的说明，并跑通门禁。
4. 在那之前：本目录不得新增任何数据文件；确需新增空表模式时，新文件必须同样以 `_empty.csv` 命名、仅表头，并在门禁 EXPECTED 与本文件列出后方可合入。

## 违规即 FAIL（门禁强制）

- 无 `trace_id` 的落数；`trace_id` 为空、悬空或不可回链。
- 出现任何数值型结论（翻转率、计数、百分比）而无对应数据行支撑。
- 表头被改动（增删改列、改顺序、改拼写）而未同步更新 W3 与门禁。
