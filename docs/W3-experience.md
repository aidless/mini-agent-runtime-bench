# W3 经验（experience）：翻转率定义与重放规范

> 本文档可独立评审。目标读者：未来的重放执行者与指标审计者。
> 一句话定位：W3 只回答“结论站得住吗”——用重放下的翻转率度量结论的脆弱性，定义先行、数据空缺。
> 状态：一个窄定义已经落数（脚本策略、再跑一次、逐字比对）。阶段切换与独立裁判仍是 `TBD`。`results/flip_rate_empty.csv` 仍仅表头，那是零证据哨兵，不是测得为零。有分子分母的文件是 `results/flip_rate.csv`，行内必须有 `trace_id` 链和 `evidence`。

## 目的与范围

- 目的：把“这个结论有多脆弱”变成一个可复算的定义，使未来的每一次翻转率都有据可查。
- 范围内：翻转率的文字定义、扰动矩阵三轴、空 csv 的列契约、脚本策略这一格点的计数表、反作弊、验收标准。
- 范围外：运行时的具体行为（归 W2）；阶段切换与独立裁判（仍是 `TBD`）；任何 LLM 智能体的能力数字。

## 定义：翻转率（flip-rate）

翻转率 = 在全部重放中结论发生翻转的重放所占的比例（文字定义；分子分母的计数规则见重放表模式）。

- “一次重放”：取一条 W2 有效轨迹，在扰动矩阵的一个格点下重新执行并重新判定，产出一行重放记录。
- “翻转”：重放结论与原轨迹 `verdict` 不一致（文字比对，不引入数值阈值，阈值事项记 `TBD`）。
- 本仓库已经冻结的一个格点：对每条脚本策略轨迹再执行一次（`run_index` 从基线走到重放）。翻转 = 两次 `verdict` 字符串不同。裁判 = 与冻结金答案逐字相等。这不是独立裁判。
- 空仓推论：`flip_rate_empty.csv` 没有数据行时，禁止用它计算翻转率，也禁止把空表说成零。**零重放绝不等于翻转率为零**。已落数的 `flip_rate.csv` 是另一份文件，其计数只在 trace 能回链时有效。

## Schema：扰动矩阵三轴（格点水平全部 TBD）

| 轴 | 含义 | 格点说明 |
| --- | --- | --- |
| 条件扰动 | 对同一快照施加受控的输入扰动 | 扰动种类与强度待定，全部 `TBD`；未定前不得重放 |
| 阶段切换 | 在运行的不同阶段切入切换 | 切换点定义待定，全部 `TBD` |
| 裁判重判 | 更换独立裁判重新判定同一轨迹 | 裁判独立性标准待定，全部 `TBD`；自判自重判无效 |

三轴的每一组合称为一个格点。当前落数只覆盖「再跑一次」这一个格点，并且裁判是逐字比对而不是独立裁判。阶段切换与裁判独立性标准仍是 `TBD`。把这一个格点的计数说成三轴翻转率，视为无效报告。

## Schema：重放表模式（= `results/flip_rate_empty.csv` 列契约）

空表哨兵仍是 `results/flip_rate_empty.csv`，只保留表头。列契约不变：

`trace_id, task_id, condition, run_id, flip_occurred, flip_type, evidence_path, notes`

脚本策略这一格点的计数表是 `results/flip_rate.csv`（分子 `flips`、分母 `replays`、`trace_ids`、`evidence_path`）。证据文件是 `results/scripted_traces.jsonl`。没有 trace id 或证据文件不存在的行，门禁判失败。空表哨兵里仍然禁止追加数据行。

## 不变量 / 反作弊（anti-gaming）

- **AG-W3-1 禁活取数**：重放不得引入冻结快照之外的实时数据；任何依赖外部实时状态的重放判无效。
- **AG-W3-2 禁挑格点**：已经纳入报告的策略必须全部出现。只报稳定策略、藏起会翻转的策略，报告无效。尚未冻结的轴（阶段切换、独立裁判）记 `TBD`，不得假装已经覆盖。
- **AG-W3-3 裁判必须独立**：重判者不得是原轨迹的产生者。独立性标准未定前（`TBD`），逐字比对只能标成「与金答案逐字相等」，不能标成独立裁判。当前脚本策略与金答案来自同一 `spec`，因此不满足本条的独立性，结果页必须写明这一点。
- **AG-W3-4 空表不得计算指标**：`flip_rate_empty.csv` 没有数据行时禁止计算、禁止外推、禁止用“无翻转观测”暗示结论稳健。有计数的只能是带 trace id 与证据的 `flip_rate.csv`。

## 与其他支柱的关系

- W3 消费 W2：只接受满足 W2 不变量的有效轨迹，无效轨迹不得重放。
- W3 引用 W1：重放必须标注原轨迹绑定的 `snapshot_id`，但不触碰快照。
