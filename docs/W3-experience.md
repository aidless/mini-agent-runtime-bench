# W3 经验（experience）：翻转率定义与重放规范

> 本文档可独立评审。目标读者：未来的重放执行者与指标审计者。
> 一句话定位：W3 只回答“结论站得住吗”——用重放下的翻转率度量结论的脆弱性，定义先行、数据空缺。
> 状态：pre-W1，全部取值 `TBD`，`trace_id: null`，`evidence: none`。`results/flip_rate_empty.csv` 仅表头，零数据行。

## 目的与范围

- 目的：把“这个结论有多脆弱”变成一个可复算的定义，使未来的每一次翻转率都有据可查。
- 范围内：翻转率的文字定义、扰动矩阵三轴、重放表模式（即空 csv 的列契约）、反作弊、验收标准。
- 范围外：运行时的具体行为（归 W2）；任何真实翻转率数值（空仓阶段不存在，全部 `TBD`）。

## 定义：翻转率（flip-rate）

翻转率 = 在全部重放中结论发生翻转的重放所占的比例（文字定义；分子分母的计数规则见重放表模式）。

- “一次重放”：取一条 W2 有效轨迹，在扰动矩阵的一个格点下重新执行并重新判定，产出一行重放记录。
- “翻转”：重放结论与原轨迹 `verdict` 不一致（文字比对，不引入数值阈值，阈值事项记 `TBD`）。
- 空仓推论：当前重放数为零，翻转率无定义，记 `TBD`；**零重放绝不等于翻转率为零**。

## Schema：扰动矩阵三轴（格点水平全部 TBD）

| 轴 | 含义 | 格点说明 |
| --- | --- | --- |
| 条件扰动 | 对同一快照施加受控的输入扰动 | 扰动种类与强度待定，全部 `TBD`；未定前不得重放 |
| 阶段切换 | 在运行的不同阶段切入切换 | 切换点定义待定，全部 `TBD` |
| 裁判重判 | 更换独立裁判重新判定同一轨迹 | 裁判独立性标准待定，全部 `TBD`；自判自重判无效 |

三轴的每一组合称为一个格点；格点枚举表在矩阵冻结前记 `TBD`，冻结后作为 W3 附录追加（追加时同步更新门禁白名单）。

## Schema：重放表模式（= `results/flip_rate_empty.csv` 列契约）

重放表即 `results/flip_rate_empty.csv`，当前仅表头。列定义与落数规范见 `results/README.md`，此处重申列契约：

`trace_id, task_id, condition, run_id, flip_occurred, flip_type, evidence_path, notes`

- 每一数据行对应一次重放；行内的 `trace_id` 必须非空且可链回原轨迹的 `run_id`。
- 在首个真实 `trace_id` 落盘之前，禁止追加任何数据行；追加即进入 W3 落数阶段，须同步满足 `results/README.md` 的落数规范。

## 不变量 / 反作弊（anti-gaming）

- **AG-W3-1 禁活取数**：重放不得引入冻结快照之外的实时数据；任何依赖外部实时状态的重放判无效。
- **AG-W3-2 禁挑格点**：重放必须覆盖扰动矩阵的全部格点组合（组合清单 `TBD`，冻结前不得重放）；只报有利格点、隐瞒翻转格点的报告无效。
- **AG-W3-3 裁判必须独立**：重判者不得是原轨迹的产生者，独立性标准未定前（`TBD`）任何重判结果不得落数。
- **AG-W3-4 空表不得计算指标**：重放数为零时禁止计算、禁止外推、禁止用“无翻转观测”暗示结论稳健；翻转率保持 `TBD`，违反本条的文档判不合格。

## 验收标准

- [ ] 定义可复算：评审人能从本文档推导出“给定重放表，如何算出翻转率”的唯一过程（当前因零重放而结果为 `TBD`）。
- [ ] 四条反作弊条款逐条可判定：给定一份候选重放报告，能明确判有效 / 无效并指出违反条款编号。
- [ ] 空仓诚实性：本文档与空 csv 中不出现任何翻转率数值、重放计数与示例结论，全部占位值保持 `TBD` / `null` / `none`。
- [ ] 本文档变更后，`python tools/check_gates.py` 仍全 PASS（A2-pillars 子项覆盖字段表、反作弊、验收三要素的存在性）。

## 与其他支柱的关系

- W3 消费 W2：只接受满足 W2 不变量的有效轨迹，无效轨迹不得重放。
- W3 引用 W1：重放必须标注原轨迹绑定的 `snapshot_id`，但不触碰快照。
