# P4 · 噪声下限门（judge 判分金标复现率）

> 本页只描述**门与接线点**，不含 bench 语义，**不产生也不声称任何 bench 数字**。
> 任何数字出现在本页都必须带 `allow-number` 标记，否则 A3-honesty 门会 FAIL。

## 为什么需要这一门

C 线将来跑出 pass/fail 时，判分有两类来源：人工金标，或 judge 自动判分。
两者的可信度不同：**judge 判的准确率本身没有被量过**，它对人工答案的复现率是一个未知数，
而所有名次、翻转率、延迟指标都建立在这个未知数上。

如果 judge 自己就能答对大部分题，那么「谁比谁强」测的其实是
「谁更像这个 judge」，不是「谁更强」。此时榜单在名义上可读、实质上不可读。

## 门在哪一步插入

| 阶段 | 插在 | 拒收时的行为 |
|---|---|---|
| 生成结果 | 写入 `results/` 之前 | 该臂标 `unscored`，不写任何行 |
| 合并指标 | 任何均值/排名计算之前 | 排除 `unscored` 臂，并在结果里显式列出被排除的臂 |
| 发布榜单 | 生成排名表之前 | 名次表降级为「原始引用 + 附审计报告」，不排名次 |

## 当前状态：已接入，未取证（SKIP）

`python3 tools/check_judge_gold_gate.py` 在没有审计报告时返回 SKIP，含义是：

- 不计 PASS，也不计 FAIL；
- 在量出 judge 对人工金标的复现率之前，任何由 judge 判分推出的名次或计数
  都不得被引用为「可读」；
- 该臂标 `unscored`，不参与任何均值与排名。

这是诚实结果，不是失败。本仓是空仓（allow-number：空仓契约见 `results/README.md`），
没有结果就没有 judge 判分，也就没有可审计的分母——在分母为零时谈复现率没有意义。

**为什么不用 0 代替 SKIP**：0 会伪装成「测过且全错」。SKIP 与 0 在下游聚合里的行为
完全不同：0 会被算进均值并把均值拉低，SKIP 会被排除且留下痕迹。

## 转成 PASS 需要补齐什么

1. 建一批人工金标（`allow-number`：不少于 200 条，题量太小则门禁失去区分力）；
2. 让 judge 在它拿不到答案的 holdout 题上作答（避免泄漏）；
3. 跑噪声下限审计并落盘报告：`allow-number` 阈值取自
   `tools/bench-noise-floor/README.md` 的实测留一法下限量级，不是随手取的整数。

## 判分档位

| 档位 | 含义 | 本仓的处理 |
|---|---|---|
| READABLE | 榜首明确高于 judge 复现率 | 正常收录 |
| MARGINAL | 榜首与下限的余量不足以支撑名次 | 收录但名次表必须并列两种金标口径，且必须报 CI |
| UNREADABLE | 下限高于榜首 | 一律拒收，该臂 `unscored` |

## 门必须能失败

`python3 tools/check_judge_gold_gate.py --selftest` 是这个门的非空性反证：
它注入十种违规报告（判决不可读、复现率不足、题量不足、缺字段、手改报告、
非法档位、下限越界、榜单为空等），任一条没被拦住就返回 `allow-number`：门失效。
这也是 R5 非空性纪律在本页的延续——门若恒真，本项 FAIL。
